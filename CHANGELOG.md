# Changelog

## [0.1.0] - 2026-11-16

- First release: a Convex component that sends SMS and OTP through kwtSMS. Queued sending with message status (queued, sending, sent, failed), an `onSmsEvent` callback, an idempotency key, Kuwait number normalization with a country allowlist, per-number, global and daily-points caps, English and Arabic OTP texts, and test mode by default.
